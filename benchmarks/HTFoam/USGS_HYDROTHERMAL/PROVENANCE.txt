HTFoam comparison reference identities

Original .input/.hti and historical h1-h3 reference tables are unchanged.
Vertical reference.csv and 2D reference-YEARyr.csv are byte-for-byte copies of
validated output extractions from the independent USGS HYDROTHERM 3.2.0 runs.
Temperatures are Celsius; the CSVs preserve native coordinates, pressure in bar
and MPa, and the established mapping to OpenFOAM coordinates. Years are 365.25
days except the retained h1 compatibility comparison clock (365 days).

Official source: https://volcanoes.usgs.gov/software/hydrotherm/downloads/htsrc-3.2.0.zip
Source archive SHA256: 155a1dd013823507c3be12fee855cfc7d53f0dae74383b15a9a0efa8e44596ab
Audited executable SHA256: 64cd0177049e369a2abf629c10debd787f7341bc6432364eca2ae1fc82aca374
Environment: GNU Fortran 11.4, native Linux ARM64. Production flags were -O2
-ffree-line-length-none, plus -fno-range-check for printopt.f90's disabled-output
sentinel only. No official source edits or production floating-point traps.
The h1-h3 historical profiles have weaker executable/raw-output provenance.
Neither reference time/grid convergence nor identical EOS implementations is claimed.

The independent build recipe remains available from Git history:
  git show 2c61360d:benchmarks/HTFoam/USGS_HYDROTHERMAL/reference-review/BUILD.md
A complete verified pre-simplification source copy is retained locally at:

ignored benchmark root. Default comparisons need only the frozen tables here.
