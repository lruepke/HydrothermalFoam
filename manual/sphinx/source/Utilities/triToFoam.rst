*******************
triToFoam
*******************

|triToFoam| is designed to convert mesh generated by |tri| to OpenFOAM's polyMesh format. 
The required |tri| mesh file are :code:`.node`, :code:`.ele`, :code:`.edge` files.

Build 
==============

|triToFoam| just like the normal OpenFOAM app, it can be compiled using command :code:`wmake`. 
While if you would like to use cmake, I also provide the cmake configuration file.
This could be useful if you want to debug it in an IDE, e.g. Xcode.

.. tab:: Xcode

    .. code:: bash

        cd triToFoam
        mkdir build
        cd build
        cmake -GXcode ..

.. tab:: Unix makefile

    .. code:: bash 

        cd triToFoam
        mkdir build
        cd build
        cmake ..
        make 

Usage
==========

It is quite easy to use |triToFoam| to convert |tri| mesh to polyMesh, just like the OpenFOAM build-in utility :code:`gmshToFoam`.

1. Required input files: :code:`.node`, :code:`.ele`, :code:`.edge` files.
2. Optional input file: :code:`.bm2name` file. This file defines the map from |tri| boundary markers to the final patch names of polyMesh. The :code:`.bm2name` file include two columns, the first column is the |tri| boundary marker (an integer number), the second column is the user defined patch name for the final polyMesh. Note that, the :code:`front` and :code:`back` patches are automatically created by |triToFoam| and their patch type is set to :code:`empty`. 
3. Optional input file: :code:`.attrib2name` file. This file defines the map from |tri| element attributes to cellZone names of the final polyMesh. Otherwise the default cellZone names will be in pattern :code:`zone#attribute`.
4. Optional argument: :code:`-zmin`, :code:`-zmax`

There is a test case can be found in the folder of |triToFoam| source code folder. You could use the |tri| command :code:`triangle  -pQIq20Aane  Triangle/box.poly` to generate |tri| mesh first, then use :code:`triToFoam Triangle/box` to convert it to polyMesh. Test command as below,

.. code:: bash
    
    cd testCase
    triangle  -pQIq20Aane  Triangle/box.poly
    triToFoam Triangle/box.node
    checkMesh

The initial .poly file and the |tri| mesh files of this example case are listed below,

:download:`triToFoam/box.poly`, :download:`triToFoam/box.node`, :download:`triToFoam/box.ele`, :download:`triToFoam/box.edge`, :download:`triToFoam/box.bm2name`.

    The source code can be found at https://gitlab.com/hydrothermal-openfoam/gmsh, and the macOS app can be download from https://github.com/zguoch/gmsh/releases. 
    The .geo file for the above example case is here: :download:`triToFoam/box.geo`.
