There are five highlights in the pipe model.

#. To simulate a focused upflow zone in the deeper crust (e.g. layer 2B) where permeability is sufficiently low (:math:`k=10^{-15}\ m^2`) to allow for high-temperature fluid flow, a :code:`hydrothermalMassFluxPressure` (:math:`\phi=1\ g/m^2/s`) boundary condition for puressure and :code:`fixedValue` (:math:`T_{bot} = 400\ ^{\circ}\text{C}`) boundary condition for temperature are applied on the pipe bottom.

#. Hybrid mesh, triangular mesh and regular mesh, is generated by gmsh_ . The mesh in the central zone is regular.

#. Different resolution of mesh is set by gmsh_ .

#. Permeability field is specified with different value for layer 2A and layer 2B by :code:`zoneToCell` keyword in :code:`setFieldDict` file.

#. To simulate hydrothermal flow discharge out of seafloor, a :code:`inletOutlet` boundary condition of temperature is applied on the pipe top.
