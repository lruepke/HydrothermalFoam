Current maintained collection
=============================

The current OF10 / HTFoam-review collection consists of exactly five examples:

* :download:`Uniform 2D box <../../../../tutorials/cookbooks/2d/Regular2DBox/README.md>`
* :download:`Layered permeability <../../../../tutorials/cookbooks/2d/Regular2DBox_layered/README.md>`
* :download:`Exponential permeability <../../../../tutorials/cookbooks/2d/Regular2DBox_exp_perm/README.md>`
* :download:`Gmsh / Triangle alternatives <../../../../tutorials/cookbooks/2d/gmsh2DBox/README.md>`
* :download:`3D convection <../../../../tutorials/cookbooks/3Dbox/README.md>`

Use the :download:`maintained tutorial list <../../../../readme.md>`
for prepare/run/visualization instructions and qualification limits.
